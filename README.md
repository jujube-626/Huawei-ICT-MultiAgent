# Huawei ICT Multi-Agent

> 华为ICT大赛 · 创新赛参赛项目  
> 基于 Multi-Agent 的智能电子设计与工程协作系统

## 📌 项目简介

本项目面向电子工程场景，构建一个基于大语言模型（LLM）的 Multi-Agent 智能协作系统。

系统模拟真实电子工程团队的工作方式，通过多个具有不同专业能力的 Agent 进行任务分工、协同推理、知识检索、工具调用与结果验证，实现从自然语言需求到电子产品方案的智能化辅助设计。

项目希望探索：

> **让 AI 不只是回答电子问题，而是像一个真正的电子工程团队一样协同完成任务。**

---

## 🎯 项目目标

传统电子产品开发通常需要经历：

需求分析 → 方案设计 → 器件选型 → 硬件设计 → 软件开发 → 测试验证 → 项目文档

本项目尝试利用 Multi-Agent 技术，将上述流程中的不同专业角色进行智能化协作。

最终实现：

```text
用户提出需求
      ↓
任务规划
      ↓
需求分析
      ↓
硬件方案设计
      ↓
器件选型
      ↓
嵌入式代码生成
      ↓
电路方案检查
      ↓
测试方案生成
      ↓
项目文档生成
      ↓
完整电子产品方案
## 👥 三人分工

项目采用“三人协同开发”的方式，分别负责 AI Agent、知识库与后端系统、前端与硬件 Demo 三个方向。

### 👤 成员 A —— Multi-Agent / AI 核心

主要负责智能体系统的设计与开发。

工作内容：

- Multi-Agent 整体架构设计
- Planner Agent 开发
- Requirement Agent 开发
- Hardware Agent 开发
- Software Agent 开发
- Agent 间通信机制
- Prompt Engineering
- LLM API 接入
- LangGraph 工作流设计
- Agent 状态管理
- 任务规划与任务分解

核心目标：

> 实现多个 Agent 从“独立回答”向“协同完成任务”转变。

---

### 👤 成员 B —— RAG / 后端 / 工具系统

主要负责专业知识库、后端服务以及 Agent 工具调用。

工作内容：

- 电子工程知识库构建
- Datasheet 文档处理
- RAG 检索系统
- 向量数据库
- 元器件参数数据库
- Tool Calling
- 电路计算工具
- 器件查询工具
- FastAPI 后端
- Agent API 接口
- 数据存储与管理

核心目标：

> 让 Agent 不只是依靠大模型“猜答案”，而是能够检索专业资料并调用真实工具完成工程任务。

---

### 👤 成员 C —— 前端 / 嵌入式 / 实际 Demo

主要负责用户交互界面、嵌入式设备以及最终产品 Demo。

工作内容：

- Web 前端开发
- Agent 工作流可视化
- 用户需求输入界面
- Agent 执行状态展示
- 设计方案展示
- ESP32 / Arduino 开发
- 传感器接入
- 执行器控制
- Agent 与硬件通信
- 实际电子产品 Demo
- 系统联调
- 比赛现场 Demo

核心目标：

> 将后端的 Multi-Agent 系统与真实电子硬件连接起来，实现“AI → 代码 → 硬件”的完整闭环。
